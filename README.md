# AWS VPC and EC2 Deployment

## Project overview

Created a custom AWS VPC architecture with a public subnet and deployed an EC2 instance.

## Work completed

- Created a custom VPC.
- Created a public subnet.
- Configured an Internet Gateway.
- Created and associated a route table.
- Configured security group rules.
- Deployed an EC2 instance.
- Tested network connectivity.

## AWS services used

- Amazon VPC
- Amazon EC2
- Internet Gateway
- Route Tables
- Security Groups

## Skills demonstrated

- AWS networking
- Subnetting
- Routing
- Cloud security
- EC2 deployment
- Network troubleshooting

## Important note

This project contains no passwords, AWS access keys, private keys, or sensitive information.
